# Практическая работа: Сортировка трех чисел (Sort3)

## Описание
Программа на C# реализует статический класс `Order` с методами `Swap` (обмен значений по ссылке) и `Sort3` (упорядочивание трех чисел по возрастанию исключительно через вызовы метода `Swap`).

## Проверка на требуемых тестах
* 3 1 2 -> 1 2 3
* 1 2 3 -> 1 2 3
* 3 2 1 -> 1 2 3
* 2 2 1 -> 1 2 2
* 5 5 5 -> 5 5 5
