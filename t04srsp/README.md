# Практическая работа: Статистика оценок (методы)

## Описание
Программа на C# для сбора и анализа статистики оценок с использованием статического класса `Grades`, констант (`Min`, `Max`, `Stop`) и разделения логики на методы (`Read`, `IsValid`, `PrintStats`).

## Результаты тестирования

### Тест 1
* **Ввод:** 5, 4, 5, 0
* **Вывод:**
  * Всего оценок: 3
  * Сумма баллов: 14
  * Количество пятерок: 2
  * Средний балл: 4.67

### Тест 2
* **Ввод:** 0
* **Вывод:**
  * Оценок нет

### Тест 3
* **Ввод:** 3, 7, abc, 2, 0 *(значения 7 и abc являются некорректным вводом и игнорируются)*
* **Вывод:**
  * Всего оценок: 2
  * Сумма баллов: 5
  * Количество пятерок: 0
  * Средний балл: 2.50
