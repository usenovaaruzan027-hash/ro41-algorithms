# Практическая работа: Перевод секунд в часы, минуты и секунды

## Описание
Программа на C#, переводящая секунды в формат ч:м:с с защитой от некорректного ввода.

## Результаты тестирования
| Входные данные ($N$) | Результат |
| :--- | :--- |
| **3725** | 1 ч. 2 мин. 5 сек. |
| **59** | 0 ч. 0 мин. 59 сек. |
| **86399** | 23 ч. 59 мин. 59 сек. |
| **0** | 0 ч. 0 мин. 0 сек. |
| *текст / отрицательное* | Ошибка: введено некорректное значение. |
