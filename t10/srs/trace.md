# Трассировка алгоритмов сортировки и поиска

## 1. Сортировка выбором (Selection Sort)
**Исходный массив:** a = {5, 2, 9, 1, 7}

### Таблица трассировки
| Проход (i) | Индекс минимума | Массив после обмена | Число сравнений на проходе |
| :---: | :---: | :--- | :---: |
| 0 | 3 | {1, 2, 9, 5, 7} | 4 |
| 1 | 1 | {1, 2, 9, 5, 7} | 3 |
| 2 | 3 | {1, 2, 5, 9, 7} | 2 |
| 3 | 4 | {1, 2, 5, 7, 9} | 1 |

* **Общее число сравнений:** 4 + 3 + 2 + 1 = 10.

## 2. Сортировка вставками (Insertion Sort)
**Исходный массив:** a = {4, 3, 2, 1}

### Таблица трассировки
| i | key | Число сдвигов | Массив после вставки |
| :---: | :---: | :---: | :--- |
| 1 | 3 | 1 | {3, 4, 2, 1} |
| 2 | 2 | 2 | {2, 3, 4, 1} |
| 3 | 1 | 3 | {1, 2, 3, 4} |

* **Всего сдвигов:** 1 + 2 + 3 = 6.
* **Число сравнений на уже отсортированном массиве из 4 элементов:** Ровно 3 сравнения (по 1 сравнению на каждый элемент).

## 3. Бинарный поиск (Binary Search)

### А) Поиск элемента x = 7 в массиве {1, 3, 5, 7, 9, 11, 13}
| Шаг | lo | hi | mid | a[mid] | Решение |
| :---: | :---: | :---: | :---: | :---: | :--- |
| 1 | 0 | 6 | 3 | 7 | Найдено (7 == 7), возврат индекса 3. |

### Б) Поиск элемента x = 6 в том же массиве
| Шаг | lo | hi | mid | a[mid] | Решение |
| :---: | :---: | :---: | :---: | :---: | :--- |
| 1 | 0 | 6 | 3 | 7 | 7 > 6, сдвигаем hi = mid - 1 = 2 |
| 2 | 0 | 2 | 1 | 3 | 3 < 6, сдвигаем lo = mid + 1 = 2 |
| 3 | 2 | 2 | 2 | 5 | 5 < 6, сдвигаем lo = mid + 1 = 3 |

* **Чем закончится поиск:** Поиск завершится неудачно (lo > hi), элемент не найден (-1).
* **Какое значение вернёт LowerBound(6):** Вернет индекс 3 (так как под этим индексом находится число 7 — первый элемент, который >= 6).
